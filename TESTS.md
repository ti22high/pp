# TESTS.md — 30 ручных smoke-тестов

Прогонять после каждой фазы. Каждый тест: **Предусловие → Шаги → Ожидаемый результат**.

Тесты привязаны к фазам — после Phase N запускать тесты с пометкой `[P1..PN]`. Тесты позднейших фаз пропускать, пока фаза не достигнута.

Формат прохождения: ставить `✅ <дата>` или `❌ <дата> — <короткое замечание>` в начале строки.

## Phase 1 — Foundation

### 1. [P1] Приложение запускается в dev-режиме
- **Предусловие:** `npm install` успешно завершился; нет запущенных копий Electron.
- **Шаги:**
  1. В корне репозитория выполнить `npm run dev`.
  2. Подождать сборку Vite + старт Electron.
- **Ожидаемый результат:** Открывается окно SlidesClone, виден базовый layout (header / filmstrip слева / canvas в центре / inspector справа). Консоль без красных ошибок.

### 2. [P1] Шрифты загружаются с кириллицей
- **Предусловие:** Тест 1 пройден; в `resources/fonts/` есть woff2 файлы.
- **Шаги:**
  1. Запустить `npm run dev`.
  2. Открыть DevTools → Network → Fonts.
  3. В консоли: `[...document.fonts].map(f => f.family + ' ' + f.status)`.
- **Ожидаемый результат:** Все ~20 шрифтов в статусе `loaded`. В консоли нет «failed to decode». Текст «Привет мир» в любом блоке рендерится в выбранном шрифте, не в fallback.

### 3. [P1] Главное меню работает (RU/EN)
- **Предусловие:** Окно открыто.
- **Шаги:**
  1. Кликнуть в меню по File → видны пункты New / Open / Save / Save As / Recent / Exit.
  2. Edit / View / Insert / Slide / Format / Help — все открываются.
- **Ожидаемый результат:** Меню не пустое, все 7 разделов присутствуют, акселераторы (подчёркнутые буквы) видны.

## Phase 2 — Core editor

### 4. [P2] Создание нового слайда
- **Предусловие:** Открыт пустой проект (1 слайд по умолчанию).
- **Шаги:**
  1. Ctrl+M (или Slide → New slide).
- **Ожидаемый результат:** В filmstrip появляется второй слайд; он становится активным; в основной области — пустой canvas 1920×1080.

### 5. [P2] Дублирование и удаление слайда
- **Предусловие:** В проекте ≥ 2 слайда.
- **Шаги:**
  1. ПКМ по второму слайду в filmstrip → Duplicate slide.
  2. ПКМ по дубликату → Delete.
- **Ожидаемый результат:** После duplicate — 3 слайда, активен дубликат. После delete — снова 2, активен предыдущий.

### 6. [P2] Drag фигуры (Rect)
- **Предусловие:** Открыт пустой слайд.
- **Шаги:**
  1. В toolbar нажать Rectangle, кликнуть на canvas — появится прямоугольник 200×100.
  2. Захватить мышью и перетащить в другое место.
- **Ожидаемый результат:** Прямоугольник следует за курсором плавно (60 FPS на глаз), без рывков. После отпускания — остаётся в новой позиции; в Inspector x/y обновились.

### 7. [P2] Resize и rotate через Transformer
- **Предусловие:** На слайде есть выделенный прямоугольник.
- **Шаги:**
  1. Потянуть угловой хэндл — изменить размер.
  2. Потянуть верхний rotate-хэндл — повернуть на ~45°.
- **Ожидаемый результат:** Размер и угол меняются плавно; в Inspector обновляются w/h и rotation. Текст внутри (если есть) масштабируется.

### 8. [P2] Текст: ввод и форматирование (тулбар сверху)
- **Предусловие:** Открыт слайд.
- **Шаги:**
  1. Тулбар «Текст» → двойной клик по надписи → правка на месте; ввести «Hello Привет 你好».
  2. Сверху — контекстный тулбар «Текст». Выделить всё (Ctrl+A) и сменить шрифт (напр. Montserrat), размер (32), нажать Ж/К/Ч, задать цвет, выравнивание по центру, межстрочный 1.5.
  3. Кликнуть вне надписи (правка закрывается).
- **Ожидаемый результат:** Текст в Konva отображается выбранным шрифтом/размером/цветом, жирным/курсивом/подчёркнутым, по центру, с интервалом 1.5 — так же, как в правке. Кириллица не «квадраты». Тулбар не закрывает правку при клике по нему.

### 9. [P2] Undo / Redo
- **Предусловие:** Сделаны несколько действий (добавить фигуру, переместить, изменить цвет).
- **Шаги:**
  1. Ctrl+Z трижды.
  2. Ctrl+Y дважды.
- **Ожидаемый результат:** Каждое undo откатывает ровно одно действие. Redo восстанавливает. История не «теряется» при undo + новое действие (стандартное поведение: redo-ветка сбрасывается).

### 10. [P2] Smart guides и snap
- **Предусловие:** На слайде ≥ 2 фигуры.
- **Шаги:**
  1. Тащить одну фигуру близко к другой по вертикали.
- **Ожидаемый результат:** Появляются голубые линии-направляющие при совпадении центров/краёв. Фигура «прилипает» с порогом ~6 px / scale.

### 10a. [P3] Направляющие при повороте
- **Предусловие:** На слайде фигура (можно ещё одну для совпадения краёв).
- **Шаги:**
  1. Поставить фигуру по центру слайда; вращать её rotate-хэндлом.
  2. Вращать фигуру так, чтобы край её повёрнутого bbox совпал с центром/краем слайда или другой фигуры.
- **Ожидаемый результат:** Во время поворота появляются те же направляющие, что и при перетаскивании (центр/края слайда и других фигур). Сам угол при этом не привязывается, позиция не дёргается; по окончании поворота линии исчезают.

### 11. [P2] Copy / Paste / Duplicate
- **Предусловие:** Выделена фигура.
- **Шаги:**
  1. Ctrl+C, кликнуть на пустое место слайда, Ctrl+V.
  2. Выделить фигуру → Ctrl+D.
- **Ожидаемый результат:** После Ctrl+V — копия со сдвигом ~10/10 от оригинала. После Ctrl+D — дубликат с тем же сдвигом, остаётся выделенным.

### 12. [P2] Группировка / разгруппировка
- **Предусловие:** Выделены 2+ фигуры (Shift+click).
- **Шаги:**
  1. Ctrl+Alt+G.
  2. Двинуть группу.
  3. Ctrl+Alt+Shift+G.
- **Ожидаемый результат:** После Ctrl+Alt+G — единое выделение, фигуры двигаются вместе. После Ungroup — выделены те же отдельные фигуры.

## Phase 3 — Advanced editing

### 13. [P3] Вставка картинки drag-n-drop
- **Предусловие:** На рабочем столе есть PNG/JPG.
- **Шаги:**
  1. Перетащить файл на canvas.
- **Ожидаемый результат:** Картинка появляется в точке drop с пропорциональным fit (≤ 800×600). В Inspector — Replace, Crop, Recolor.

### 14. [P3] Crop и Crop-to-shape
- **Предусловие:** Картинка выделена.
- **Шаги:**
  1. Inspector → Crop → потянуть один из 8 хэндлов внутрь.
  2. Inspector → Crop to shape → выбрать «Ellipse».
- **Ожидаемый результат:** После crop — видимая область уменьшилась, исходник не потерян (Reset вернёт). После mask — картинка обрезана по эллипсу.

### 15. [P3] Таблица: вставка и редактирование
- **Предусловие:** Пустой слайд.
- **Шаги:**
  1. Insert → Table → 3×3.
  2. Двойной клик в ячейку, ввести «Привет 123».
  3. ПКМ по строке → Insert row above.
- **Ожидаемый результат:** Таблица 3×3 появляется по центру слайда. Текст вводится корректно. После insert row — 4 строки.

### 16. [P3] LaTeX-формула
- **Предусловие:** Открыт слайд.
- **Шаги:**
  1. Insert → Equation.
  2. Ввести `\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}`.
- **Ожидаемый результат:** Live preview сразу показывает рендер KaTeX; после Insert — формула на слайде как overlay; масштабируется со стейджем при зуме.

### 17. [P3] Connector с auto-snap
- **Предусловие:** На слайде 2 фигуры в разных местах.
- **Шаги:**
  1. Insert → Elbow connector.
  2. Кликнуть рядом с первой фигурой — линия «прилипает» к точке соединения.
  3. Протянуть и отпустить рядом со второй.
- **Ожидаемый результат:** Connector соединил две фигуры по точкам connection. При перемещении любой фигуры — connector следует.

### 17a. [P3] Image-fill для фигуры
- **Предусловие:** На слайде есть прямоугольник (или эллипс/path).
- **Шаги:**
  1. Выделить фигуру → правая панель → секция «Заливка» → режим «Картинка».
  2. В файловом диалоге выбрать изображение.
  3. Растянуть фигуру за угол (resize).
- **Ожидаемый результат:** Картинка появляется внутри фигуры, растянутая на её bbox; при resize тянется вместе с фигурой (без выхода за края у эллипса). В инспекторе видно превью и кнопку «Заменить изображение…».

### 17b. [P3] Shape library (библиотека фигур)
- **Предусловие:** Открыт слайд.
- **Шаги:**
  1. На тулбаре нажать «Фигуры» — открывается поповер с категориями (Базовые / Стрелки / Блок-схема / Звёзды и выноски).
  2. Кликнуть любую фигуру (например, «Стрелка вправо»).
- **Ожидаемый результат:** Фигура вставляется по центру слайда с заливкой и обводкой, сразу выделена; превью в панели совпадает с формой на слайде. Resize/rotate работают как у обычной фигуры; заливку/обводку можно менять в инспекторе.

### 17c. [P3] Закладки (bookmarks) + ссылка на закладку
- **Предусловие:** В деке ≥ 2 слайда; на 2-м слайде есть фигура.
- **Шаги:**
  1. Выделить фигуру на 2-м слайде → правая панель → секция «Закладка» → ввести имя (напр. «Цель»).
  2. На 1-м слайде выделить другую фигуру → Вставка → Гиперссылка… (Cmd/Ctrl+K) → режим «На закладку».
  3. В списке выбрать «Цель (Слайд 2)» → Применить.
- **Ожидаемый результат:** В секции «Закладка» имя сохраняется. В диалоге гиперссылки режим «На закладку» показывает список закладок деки (имя + номер слайда); после «Применить» у фигуры стоит ссылка kind:'bookmark'. Если закладок нет — диалог подсказывает задать имя в свойствах фигуры. (Переход по ссылке — в режиме показа, Phase 6.)

### 17d. [P3] Заметки докладчика
- **Предусловие:** В деке ≥ 2 слайда.
- **Шаги:**
  1. Внизу нажать полоску «▴ Заметки» — панель раскрывается.
  2. Ввести текст заметки для слайда 1 (можно Ctrl+B — жирный).
  3. Переключиться на слайд 2 — поле пустое; ввести другую заметку.
  4. Вернуться на слайд 1 — заметка сохранилась; свернуть панель кнопкой «▾».
- **Ожидаемый результат:** Заметки привязаны к слайду (у каждого своя), сохраняются при переключении; панель сворачивается/разворачивается. Заметки не отображаются на самом слайде (только в панели; показ — Phase 6).

### 17f. [P3] Визуальный редактор формул (MathLive)
- **Предусловие:** Открыт редактор формулы (Вставка → Формула).
- **Шаги:**
  1. В визуальном поле напечатать `x=`; нажать кнопку «a/b» (дробь) — появляется дробь с пустыми слотами, курсор в числителе.
  2. Ввести числитель, Tab → знаменатель; нажать «√», «Σ», «α» — вставляются как визуальные элементы.
  3. Нажать «▸ Показать LaTeX» — внизу появляется поле с LaTeX; поправить там — визуальное поле и слайд обновляются.
  4. «Готово» — формула на слайде (рендер KaTeX). Двойной клик — снова правка.
- **Ожидаемый результат:** Формула редактируется визуально «как в Word» (слоты, кнопки-шаблоны), без обязательного LaTeX; LaTeX доступен по тогглу. Глифы формулы отображаются корректным шрифтом (KaTeX-набор). На слайде формула рендерится через KaTeX.

### 17g. [P3] Рукописный ввод символа формулы (ink → LaTeX)
- **Предусловие:** Открыт редактор формулы (Вставка → Формула).
- **Шаги:**
  1. Нажать «✏ Рисовать символ» — появляется холст с пунктирной рамкой.
  2. Нарисовать мышью/стилусом цифру (напр. «2») — на отпускании пера справа появляются 4 кнопки-варианта.
  3. Кликнуть нужный вариант — символ вставляется в визуальное поле формулы, холст очищается.
  4. Нарисовать многоштриховый символ «=» (две горизонтальные черты) — после второго штриха «=» в вариантах; выбрать.
  5. «Очистить» — холст и варианты сбрасываются.
- **Ожидаемый результат:** Рисунок распознаётся офлайн, среди top-4 вариантов есть нужный символ; выбор вставляет LaTeX в формулу. Распознаётся по одному символу (не целое уравнение). Палец/перо рисуют, не скроллят окно.

### 17e. [P3] Формула KaTeX
- **Предусловие:** Открыт слайд.
- **Шаги:**
  1. Тулбар → «Формула» — на слайде появляется плейсхолдер «формула…», открывается диалог LaTeX.
  2. Ввести `\frac{a}{b}` (или нажать кнопку-пример) — превью в диалоге и формула на слайде обновляются сразу.
  3. «Готово». Перетащить формулу, потянуть угол (масштаб), повернуть.
  4. Двойной клик по формуле — диалог открывается снова для правки.
- **Ожидаемый результат:** Формула рендерится KaTeX (дробь и т.п.), bbox обтягивает её. Перетаскивание/масштаб/поворот работают (DOM-визуал следует за фигурой). Правка LaTeX обновляет формулу вживую. Примечание: формула рисуется поверх других фигур (ограничение оверлея).

- **Ожидаемый результат:** При старте — диалог «Recover unsaved changes from <дата>?» → Yes → проект открывается со всеми последними изменениями.

### 29. [P7] Find & Replace
- **Предусловие:** В проекте есть слово «cat» в нескольких местах.
- **Шаги:**
  1. Ctrl+H → Find: `cat`, Replace: `dog`, Match case = off.
  2. Replace All.
- **Ожидаемый результат:** Все вхождения «cat» / «Cat» / «CAT» заменены на «dog» / «Dog» / «DOG» (сохраняя регистр, если реализовано) или просто `dog` (минимальная реализация). Счётчик показывает число замен.
