Сюда попадает то, что не получилось починить после: (1) §14 SPEC.md Troubleshooting, (2) обдумывания первопричины, (3) ~3–4 разумных попыток.

## Формат записи

```
### YYYY-MM-DD | Фаза N, пункт N.M | <короткое название>

- **Описание:** что именно не работает; полный текст ошибки/стека (если есть).
- **Воспроизведение:**
  1. шаг
  2. шаг
  3. шаг — наблюдаем X, ожидали Y.
- **Что пробовал:** какие гипотезы проверил и почему они не сработали.
- **Статус:** `OPEN` / `WORKAROUND` / `BLOCKED` / `FIXED (<commit-hash>)`.
- **Блокирует:** список пунктов PROGRESS.md, которые зависят от этого бага (если есть).
```

Статусы:
- **OPEN** — не починен, но не блокирует продвижение по плану.
- **WORKAROUND** — есть временное обходное решение, нужно вернуться.
- **BLOCKED** — блокирует следующие пункты, требуется решение пользователя.
- **FIXED** — починен; запись остаётся для истории с хэшем фикса.

При статусе **BLOCKED** Claude Code останавливается и сообщает пользователю.
