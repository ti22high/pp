# DECISIONS.md — журнал принятых решений

Когда `SPEC.md` не покрывает какую-то ситуацию явно, Claude Code принимает решение сам (без вопросов пользователю) и записывает его сюда. Пользователь может откатить или скорректировать решение, увидев запись.

## Формат записи

```
### YYYY-MM-DD | <короткий заголовок>

- **Контекст:** в каком пункте/фазе возникла неопределённость, что именно неясно.
- **Решение:** что конкретно сделано (или выбрано).
- **Обоснование:** почему именно так — со ссылкой на §SPEC.md / принципы / альтернативы.
```

Записи добавляются снизу (новые — внизу), чтобы хронология читалась сверху вниз.
